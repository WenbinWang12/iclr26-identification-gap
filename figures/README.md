# Figure Specifications

No result figure is included until experiments have been run.

1. `overview.pdf`: evolving source mixture, one adapter, fixed atom pool, and
   allocate/protect/consolidate/recycle transitions.
2. `capacity_dynamics.pdf`: aligned time axes for forgetting, whitened spectral
   tail, safe-dimension count, and free/protected/recycled slots.
3. `retention_heatmap.pdf`: evaluation-window by training-window retention.
4. `curvature_calibration.pdf`: predicted historical loss change versus observed
   change, with identity line and confidence intervals.
5. `rank_sweep.pdf`: performance and forgetting versus total rank for multiple
   active-rank budgets, with resource-matched baselines.

Every plot should show uncertainty and expose individual stream realizations in
the appendix. Avoid smoothing that hides abrupt forgetting or recovery.
